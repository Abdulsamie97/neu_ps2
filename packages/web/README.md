# Pseudo2 Workbench

The web workspace provides the Monaco/Langium Pseudo2 editor and the full
browser workbench for JavaScript execution, C generation, VeriFast verification
and Graphviz visualization.

Start it from the repository root:

```powershell
npm run dev
```

Open `http://localhost:20002/pseudo2-workbench`. Press `Start` to initialize the
editor and language server.

The right side has two views:

- `Outputs` contains JavaScript output, generated JavaScript, generated C,
  mapped VeriFast diagnostics, the summary and source echo.
- `Graphs` renders the AST graph, dependency graph and every generated function
  CFG. Select a graph from the dropdown or use `Refresh` after changing source.

Graphs are generated by `pseudo2-language` and rendered locally as SVG with
`@viz-js/viz`; no system Graphviz executable is required. The original DOT
source is available in the expandable `DOT Source` section.

VeriFast requests use the Vite endpoint `/api/verifast` and the repository-local
`verifast-26.01/bin/verifast.exe`. Generated C diagnostics are mapped back to
Pseudo2 source lines and shown as Monaco editor markers.
